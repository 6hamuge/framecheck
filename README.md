# FrameCheck

**영상 편집과 학회 실습을 위한 브라우저 기반 압축 전후 프레임 비교 도구**

같은 시점의 원본과 JPEG 변환본을 나란히 보고, 해상도와 품질을 바꿨을 때 얼굴이나 다른 관심 영역의 디테일이 어떻게 달라지는지 확인할 수 있습니다.

![FrameCheck에 포함된 작업실 샘플의 첫 프레임](framecheck/dist/sample-poster.jpg)

## 할 수 있는 일

- **영상 열기** · 내 MP4·WebM 파일 또는 6초 작업실 샘플을 엽니다. 입력은 현재 브라우저에서 재생 가능하고 30초·50MB 이하여야 합니다.
- **같은 영역 비교하기** · 타임라인에서 시점을 고른 뒤 영역을 드래그하거나 좌표를 입력합니다. 해상도와 JPEG 품질을 독립적으로 조절할 수 있습니다.
- **AI 얼굴 분석** · 얼굴·눈·입 영역을 자동 선택하고, 원본과 변환본에서 모델이 추정한 눈·입 특징점의 평균 위치 차이를 확인합니다.
- **PNG 저장** · 확대 이미지, 시점, 압축 설정과 선택 영역의 픽셀 크기를 한 장에 저장합니다.

영상, 프레임과 특징점은 브라우저에서 처리합니다. 처음 얼굴 분석을 실행할 때 외부에서 MediaPipe 런타임과 모델 자산을 내려받습니다. 특징점 수치는 해당 모델의 추정 차이를 나타냅니다.

## 로컬에서 실행

저장소 루트에서 실행합니다. 별도 빌드 단계 없이 HTML·CSS·JavaScript를 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory framecheck/dist
```

브라우저에서 [로컬 FrameCheck](http://127.0.0.1:8000/)를 열고 **샘플로 시작 → 시점 선택 → 얼굴 분석 또는 영역 지정 → 압축 조건 변경 → 비교 PNG 저장** 순으로 진행합니다. 압축 조건을 변경한 뒤 새 특징점 결과를 얻으려면 얼굴 분석을 다시 실행합니다.
