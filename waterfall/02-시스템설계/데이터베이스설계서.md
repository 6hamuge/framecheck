## 1. 데이터베이스 적용 여부

| 설계 항목 | 판정 | 근거 |
| --- | --- | --- |
| 서버 DBMS, ERD, 테이블, 인덱스 | 해당 없음 | 활성 작업의 상태는 사용자 브라우저 메모리에 있다. 서버에는 회원, 영상, 비교 이력 레코드를 생성하지 않는다. |
| IndexedDB, Local Storage 등 브라우저 영구 앱 저장 | 해당 없음 | 세션 복원은 MVP 범위 밖이며, 사용자 미디어는 선택한 탭의 현재 작업에서 사용한다. |
| 마이그레이션, 백업, 복구 | 해당 없음 | 서비스가 보존하는 사용자 레코드가 없다. 다운로드한 PNG는 사용자의 기기에서 관리한다. |

적용 근거는 FR-006, NFR-001, NFR-002 및 BP-LOCAL-001·BP-LOCAL-002다. 샘플 영상과 포스터는 배포 자산으로 관리한다.

## 2. 브라우저 작업 데이터 사전

| 논리 데이터 | 주요 필드 · 타입 | 유효 조건 | 수명 |
| --- | --- | --- | --- |
| 활성 영상 | 소스 종류(로컬·샘플), 표시 이름, 재생 길이(초), 원본 폭·높이(px), 소스 참조 | 양의 유효 길이와 프레임 크기. 로컬 입력은 지원 형식 및 30초·50,000,000바이트 상한 충족 | 해당 영상이 활성인 동안. 로컬 URL은 교체·종료 시 해제. |
| 프레임 | 캡처 시점(초), 원본 픽셀 이미지, 영상 및 프레임 식별자 | 같은 캡처와 확인된 시점을 두 패널이 참조 | 현재 캡처가 유효한 동안. 영상·프레임 변경 시 기존 참조 정리. |
| 선택 영역 | 원본 픽셀 정수 좌표 x·y, 폭·높이 또는 미선택 | 영상 안의 양의 면적. 화면 여백 제외. | 해당 프레임에서 유효할 때. 시점·영상 변경 시 미선택. |
| 압축 설정 | 해상도 비율, JPEG 품질(0–100) | 화면설계서의 선택 범위와 기본값 적용 | 현재 작업 영상에 유지. 새 영상은 기본값으로 시작. |
| 최신 비교 결과 | 변환 이미지, 원본·변환 영역과 각각의 실제 크기, 작업 식별자 | 활성 영상·프레임·설정·영역과 일치 | 현재 표시 결과 및 진행 중인 작업이 필요로 하는 동안. 늦게 완료한 구 결과의 참조는 정리. |
| 저장 스냅샷 | 두 크롭, 패널별 시점·크기, 압축 설정, PNG Blob | 저장 실행 시 최신 준비 상태와 일치 | 생성 및 다운로드에 필요한 동안. 기기의 PNG는 페이지 상태와 독립적으로 유지. |

## 3. 데이터 흐름과 정리

1. 정적 호스트에서 페이지·샘플 자산을 읽거나 브라우저 파일 선택으로 사용자 영상 참조를 얻는다.
2. 원본 프레임과 선택 영역, 압축 설정으로 현재 비교 이미지를 생성한다. 현재 상태와 일치하는 결과만 사용하며 시점 이동 시 관심 영역을 초기화한다.
3. 저장 요청 시 사용자 기기로 PNG를 내려받는다. 영상 교체 시 기존 영상 참조와 URL을 정리하고, 새로고침 시 시작 화면으로 돌아간다.

## 4. G2 검토와 확인 기준

| 요구사항 | 확인 방법 |
| --- | --- |
| NFR-001 / AC-008 | 로컬 영상 열기부터 PNG 저장까지 네트워크와 브라우저 저장소를 관찰한다. 영상·프레임·PNG의 서버 전송과 영구 앱 저장은 각각 0건이어야 한다. |
| NFR-002 / AC-009 | 영상을 여러 번 교체해 불필요한 객체 URL 해제를 확인한다. 새로고침으로 활성 작업이 초기화되고 이전에 받은 PNG는 사용자 기기에서 열 수 있다. |

비교 이력이나 공동 작업이 향후 범위에 들어오면 저장 대상, 접근 권한, 보존·삭제 책임부터 검토한다.

## 5. 얼굴 분석의 임시 데이터

현재 시점과 압축 설정에 연결된 정규화 점 좌표, 자동 영역 사각형, 평균 거리와 표시 상태를 메모리에 둔다. 파일·시점·설정 변경 시 결과를 지우고 늦게 온 계산 결과를 폐기한다. 브라우저가 런타임·모델의 정적 다운로드를 캐시할 수 있다. 앱 데이터 저장소, 마이그레이션 또는 얼굴 이력은 추가하지 않는다.
