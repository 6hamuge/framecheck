## 1. 서비스와 접속 정보

FrameCheck는 정적 호스트에서 페이지, 스크립트, 스타일, 샘플·포스터를 제공한다. 사용자 영상은 브라우저에서 디코딩·비교하고 PNG는 사용자의 기기에 다운로드된다. 운영 주소는 [FrameCheck](https://framecheck-vision-lab.cocoapalm5.chatgpt.site)다. ChatGPT 로그인으로 소유자 접근을 확인한다. Sites v1과 최초 배포 복구 경로는 [배포계획서](배포계획서.md)에 기록했다. 로그인 뒤 샘플·로컬 영상 저장 확인 및 운영 담당 지정은 G6에서 기록한다.

## 2. 점검과 관측

| 점검 시점 | 확인 항목 | 남길 근거 |
| --- | --- | --- |
| 배포 직후·복구 직후 | 운영 URL, 정적 파일 로딩, 샘플·포스터, 두 패널의 프레임·영역 일치, PNG 내용 | 배포 ID, 기기·브라우저, 테스트 결과 |
| 시연 전 | 실제 발표 기기에서 권리 확인 샘플과 로컬 영상으로 저장까지 진행 | 시연 환경, 시점·압축 설정, 확인 결과 |
| 문의·장애 신고 시 | 동일 후보와 지원 환경에서 재현 가능한지 확인 | 버전, 환경, 재현 절차, 오류와 상태 |
| 샘플 또는 호스팅 설정 변경 후 | 같은 출처의 자산 로딩, 권리 기록, 브라우저 네트워크·저장소 경계 | 변경 기록, 검증 환경과 증빙 |

사용자 행동 수집 도입은 MVP 범위 밖이다. 운영 점검에는 호스트의 정적 응답과 권리 확인 테스트 자산만 사용한다. 문의 기록은 기기·브라우저, 형식·크기·길이, 오류 문구를 우선 사용한다.

## 3. 장애 대응 절차

| 증상 | 확인 | 조치 |
| --- | --- | --- |
| 페이지 또는 샘플을 열 수 없음 | 호스트 응답, 배포 ID, HTML·JS·CSS·샘플·포스터 경로 및 동일 출처 확인 | 자산 누락 또는 배포 불일치면 배포 담당에게 전달하고 검증된 버전으로 복원 |
| 로컬 영상 열기 실패 | MP4·WebM 여부, 크기·길이, 대상 브라우저의 해당 코덱 재생 및 읽기 오류 확인 | 제한 사유를 안내하고 샘플 또는 지원 영상을 제시한다. 대상 환경의 회귀면 결함 등록 |
| 프레임 불일치 또는 잘못된 PNG | 시점·영역·설정 변경 순서, 최신 화면과 파일 표기 대조 | 오류 재현 절차를 남기고 배포 담당에게 사용 중단·롤백 판단을 요청 |
| 변환 또는 저장 실패 | 같은 조건에서 다시 시도하고, 대상 브라우저 및 권리 확인 자료로 반복 여부 확인 | 재시도 결과를 안내한다. 핵심 흐름이 계속 차단되면 장애로 분류 |
| 사용자 미디어의 외부 전송·영구 앱 저장 의심 | 권리 확인 테스트 데이터로 네트워크와 저장소 재현 및 실패 버전 식별 | 프로젝트 책임자와 배포 담당에게 즉시 알리고 문제가 있는 배포의 중단·복구 여부 판단 |

복구 후 운영 URL에서 샘플과 로컬 영상 비교·저장을 재확인한다. 인계 기록에는 발생 및 복구 시간(KST), 버전, 재현 근거, 조치와 후속 담당을 남긴다.

## 4. 복구 자산과 담당 역할

- **배포 담당**은 사용 가능한 정적 아티팩트, 후보 SHA, 배포 ID 및 복원 권한을 관리한다. DB 백업과 마이그레이션 복구는 해당 없음이다. 사용자가 다운로드한 PNG는 사용자 기기에서 관리한다.
- **운영 담당**은 시연 전 점검, 접수·분류, 사용자 안내 및 복구 후 확인을 맡는다. **QA**는 대상 브라우저 조합과 회귀 재현을, **프로젝트 책임자**는 배포 중단·재개 판단을 맡는다.
- 실제 담당자, 연락 채널과 대체 담당자는 G6 인수 시 기록한다. 배포 자격 증명은 승인된 경로로 전달한다.

## 5. 얼굴 분석 운영

- 얼굴 분석만 실패하면 버전, 오류 문구, 네트워크 정책, 고정 버전 JS/WASM·모델 자산 응답을 확인한다. 수동 비교와 PNG 저장의 동작도 확인한다.
- 얼굴 미검출은 작은 얼굴이나 강한 변환 조건에서 가능한 결과다. 권리 확인 샘플로 재현하고 원본 또는 변환본 미검출을 구분해 기록한다.
- 문의 자료에는 사용자의 얼굴 영상·특징점 대신 공개 가능한 픽스처, 시점, 해상도, JPEG 품질, 브라우저를 기록한다.
