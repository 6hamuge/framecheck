## 3. 게이트와 후속 검증

- 공식 QA 인수자와 G4 승인 기록은 미정이다. 검증 환경을 확정한 뒤 실제 모바일 기기 및 스크린리더에서 두 부분 검증 케이스를 재실행한다.
- AC 11개가 테스트에 연결되어 있고 테스트에서 제품 결함을 확인하지 않았다. 현재 남은 검증은 AC-010과 AC-011의 환경·접근성 항목이다.

## 4. 얼굴 분석 확장 검증

기존 집계는 Sites v1 후보의 기록이다. 아래는 macOS Codex 인앱 브라우저에서 실행한 확장 작업 폴더의 별도 검증이다. 확장 케이스 4개가 이 환경에서 통과했다. 실패·지연 주입은 별도 계측용 복사본에서 수행했다.

| 케이스 | 판정 | 확인 결과 |
| --- | --- | --- |
| TC-FN-FACE-001 | 통과 | 실제 MediaPipe 모델로 100%와 50% 샘플 분석, 얼굴·눈·입 선택, 양쪽 12개 표식 및 PNG 저장 확인. 50%에서 눈 약 0.6px, 입 약 0.8px 차이 관찰. |
| TC-FN-FACE-002 | 통과 | 단색 MP4 원본 미검출, 샘플 끝부분 25%·품질 0의 변환본 미검출 상태 확인. |
| TC-FN-FACE-003 | 통과 | 영상·시점·해상도 전환 뒤 기존 표시 제거. 모델 응답을 지연시킨 상태에서 시점을 변경하고 이전 요청을 실패시켜도 새 프레임에 이전 오류가 나타나지 않았다. 현재 시점에서 재분석 성공. |
| TC-NF-FACE-001 | 통과 | 계측한 외부 요청은 고정 버전 모듈·WASM·모델 자산이다. 확인한 fetch에는 전송 본문이 없고 Local/Session Storage는 0건. 모델 실패를 강제로 유도한 뒤 수동 비교 PNG 저장과 분석 재시도 성공. |

실제 모바일과 독립 스크린리더는 기존 제한에 포함된다. 확장 결과는 운영 배포 승인 기록으로 사용하기 전에 환경과 후보를 다시 고정한다.
