## 1. 문서 개요

FrameCheck는 영상 편집자와 학회 실습 참여자가 같은 영상 프레임과 영역에서 해상도·JPEG 품질의 영향을 비교하고 결과를 PNG로 저장하는 단일 페이지 웹앱이다. 이 명세는 기획서의 `MVP-001~007`을 대상으로 한다. 제외 범위는 딥페이크 판정·신원 식별·화질 등급·영상 구간 안정성 분석, 전체 영상 재인코딩·일괄 처리, 계정·클라우드 저장·결제다(`EX-001~003`).

| 용어 | 의미 |
| --- | --- |
| 원본 프레임 | 현재 영상의 선택 시점에서 읽은 프레임 |
| 변환 프레임 | 같은 원본 프레임의 해상도를 조절하고 JPEG로 인코딩한 결과 |
| 선택 영역 | 원본 프레임 좌표에서 지정한 양의 면적의 직사각형 |
| 최신 비교 결과 | 현재 영상·프레임·영역·압축 설정을 모두 반영한 두 패널 |

## 2. 전체 시스템 설명

사용자는 샘플 또는 로컬 영상을 열고, 타임라인으로 시점을 고른 뒤, 비교 영역과 두 압축 설정을 지정한다. 브라우저는 원본·변환 프레임과 확대 영역을 표시하고, 저장 요청에 따라 비교 PNG 다운로드를 제공한다. 브라우저의 영상 디코딩과 이미지 생성 기능이 실행 환경이다. 샘플 클립과 첫 화면의 정지 프레임은 앱 배포 자산이다.

| 작업 상태 | 사용자에게 보이는 결과 |
| --- | --- |
| 영상 열기 전 | 시작 버튼, 지원 형식과 제한, 브라우저 내부 처리 안내 |
| 영상 읽기 중 | 읽기 상태와 잠긴 비교 작업 |
| 프레임 준비 · 영역 미선택 | 두 전체 프레임과 영역 지정 안내 |
| 프레임·영역·설정 갱신 중 | 현재 조작부의 상태와 비활성 저장 버튼 |
| 최신 비교 준비 | 두 확대 영역과 수치, 활성 저장 버튼 |
| 처리 실패 | 실패 원인과 다시 시도할 방법 |

## 3. 기능 요구사항

모든 항목의 우선순위는 **P1 필수**다. 요구사항 ID와 수용 기준 ID는 유스케이스 및 RTM에서 공통으로 사용한다.

### FR-001 · 로컬 영상 열기 및 입력 검증

**출처** · MVP-001 / BP-INPUT-001, BP-INPUT-002, BP-INPUT-003, BP-STATE-002

사용자는 `내 영상 열기`로 파일을 선택할 수 있어야 한다. 현재 브라우저에서 재생 가능한 MP4·WebM으로서 크기가 **50,000,000바이트 이하**, 실제 재생 길이가 **30초 이하**인 영상의 첫 프레임을 표시한다. 지원 형식, 용량, 길이 위반은 해당 원인을 표시한다. 지원 컨테이너가 손상됐거나 브라우저가 유효한 길이 또는 프레임을 읽지 못하면 재생 실패를 표시한다. 오류 안내에서 파일을 다시 선택하거나 샘플을 열 수 있어야 한다.

**AC-001** · 유효한 MP4와 WebM을 각각 열 수 있다. 재생 가능한 파일에서 정확히 50,000,000바이트와 30초는 허용하고 한도를 각각 넘기면 해당 이유로 거부한다. 미지원 형식과 손상되거나 해독할 수 없는 MP4에는 서로 다른 안내가 표시된다. 오류 후 유효한 파일 또는 샘플을 열 수 있다.

### FR-002 · 샘플로 시작

**출처** · MVP-001 / BP-SAMPLE-001

`샘플로 시작`은 배포 및 시연 권리를 확인한 클립을 직접 연다. 첫 화면의 정지 프레임은 같은 클립에서 사용한다. 샘플을 연 뒤에는 로컬 영상과 같은 시점 선택, 영역 확대, 압축 비교, PNG 저장 기능을 제공한다.

**AC-002** · 로컬 파일 없이 샘플을 열고 PNG까지 저장한다. 배포 자산의 출처·사용 권리와 정지 프레임의 출처 클립을 확인할 수 있다.

### FR-003 · 프레임 선택 및 동기화

**출처** · MVP-002 / BP-COMPARE-001

선택된 영상의 이름과 `현재 시점 / 전체 길이`를 타임라인 근처에 표시한다. 선택한 시점에서 읽은 동일 프레임으로 원본과 변환 미리보기를 만든다. 다른 프레임이 선택되면 이전 영역을 초기화하고 영역 지정 안내를 표시한다.

**AC-003** · 영역이 지정된 상태에서 식별 가능한 다른 프레임으로 이동하면 두 카드가 같은 새 장면과 시점을 표시한다. 기존 영역의 선택선과 확대 결과가 사라지고 저장할 수 없는 상태가 된다.

### FR-004 · 관심 영역 지정 및 확대

**출처** · MVP-003, MVP-006 / BP-COMPARE-002

사용자는 원본 프레임에서 마우스나 터치로 드래그하거나 원본 픽셀 기준 좌표와 크기를 입력할 수 있어야 한다. 영상 안에 양의 면적이 있는 사각형만 유효하다. 유효 영역은 두 카드에서 같은 상대 위치에 표시한다. 같은 표시 크기로 확대하고 각 프레임과 확대 영역의 실제 가로·세로 픽셀 수를 각각 제시한다. 유효하지 않은 입력으로 비교 영역이 갱신되지 않으면 유효한 범위를 안내한다.

**AC-004** · 같은 영역을 드래그와 좌표·크기 입력으로 지정하면 두 방식의 대응 위치·확대 결과가 일치한다. 여백을 영상 영역으로 계산하지 않는다. 면적이 0이거나 영상 경계를 넘는 좌표·크기 입력은 유효한 새 영역을 만들지 않는다. 각 패널의 표시값은 실제 이미지 픽셀 크기와 일치한다.

### FR-005 · 실제 해상도 및 JPEG 품질 변환

**출처** · MVP-004 / BP-COMPARE-003 / DESIGN.md · Inputs & Forms

해상도는 원본 대비 비율, JPEG 품질은 0–100 척도로 표시한다. 변환 프레임은 원본의 종횡비를 유지해 목표 해상도로 조정한 뒤 실제 JPEG 인코딩을 거친 이미지여야 한다. 설정 변경 시 원본, 시점, 선택 영역은 유지하고 변환 결과만 갱신한다.

**AC-005** · 정수 배율로 대응시킬 수 있는 테스트 영역에 50% 해상도를 적용하면 변환 영역의 가로·세로 픽셀 수가 각각 절반으로 표시된다. 같은 해상도에서 JPEG 품질만 바꾸면 픽셀 수와 원본이 유지된다. 디테일이 있는 테스트 프레임에서 표시된 결과가 선택한 품질의 JPEG 인코딩 결과인지 확인한다.

### FR-006 · 최신 결과 기반 비교 PNG 다운로드

**출처** · MVP-005 / BP-EXPORT-001, BP-EXPORT-002, BP-LOCAL-001

유효한 영역과 최신 미리보기가 준비되었을 때 `비교 PNG 저장`을 활성화한다. 다운로드하는 PNG 한 장에는 두 확대 이미지를 나란히 담고, 각 패널의 원본·변환 라벨, 시점, 선택 영역의 실제 가로·세로 픽셀 수와 변환 해상도 비율 및 JPEG 품질을 표시한다.

**AC-006** · 영역 미선택 또는 최신 결과 생성 중에는 저장 동작을 사용할 수 없다. 준비 후 다운로드한 파일을 PNG로 열 수 있고, 두 이미지와 각 라벨·시점·픽셀 수·변환 설정이 저장 시점의 비교 화면과 일치한다.

### FR-007 · 로딩 표시, 최신 결과 및 오류 복구

**출처** · MVP-001, MVP-002, MVP-004, MVP-005 / BP-STATE-001, BP-STATE-002

영상 읽기·시점 이동·변환 중에는 해당 조작부 근처에 상태를 표시한다. 영상이나 시점·영역·설정이 바뀌면 이전 결과가 늦게 도착하더라도 최신 선택의 결과만 현재 비교와 저장에 반영한다. 압축이나 PNG 생성에 실패하면 실패 상태를 표시하고 같은 설정으로 다시 시도할 수 있어야 한다.

**AC-007** · 처리하는 동안 상태를 확인할 수 있다. 시점 및 설정을 빠르게 바꿔 완료 순서를 뒤집어도 마지막 선택과 일치하는 결과만 표시·저장된다. 변환·저장 실패를 각각 재현하면 실패 안내를 본 뒤 같은 조건으로 재시도할 수 있다.
