## 검증 범위

FrameCheck의 현재 로컬 앱을 macOS Codex 인앱 브라우저와 Python 정적 서버에서 검증한다. 샘플·로컬 영상, 시점·영역·JPEG 비교, PNG 저장, 얼굴 분석과 모델 장애 복구를 확인한다. 정체된 모델 응답은 배포 파일을 복제한 별도 계측 페이지에서 재현한다.

| 얼굴 분석·PNG | 실제 MediaPipe 모델로 샘플 끝 프레임을 분석했다. 눈 영역 선택으로 양쪽 확대를 표시하고, 내보낸 파일의 PNG 시그니처와 1280 × 548px 크기를 확인했다. |
