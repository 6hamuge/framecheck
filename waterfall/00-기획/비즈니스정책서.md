## 1. 문서 개요

FrameCheck 실습 버전의 공통 규칙을 정의한다. 각 규칙 ID는 서비스 기획서의 MVP 항목과 G0 이후 요구사항·검증 항목에서 참조한다.

- **원본 프레임**은 선택한 시점에서 브라우저가 영상으로부터 읽은 이미지다.
- **변환 프레임**은 해당 원본을 지정 해상도로 축소하고 JPEG로 인코딩한 결과다.
- **선택 영역**은 원본 프레임에서 사용자가 지정한 사각형이다. 변환 프레임에서 같은 상대 위치의 영역과 비교한다.
- **최신 비교 결과**는 현재 영상·프레임·선택 영역·변환 설정을 모두 반영한 미리보기다.

## 3. BP-INPUT · 영상 입력

**목적**  
지원 범위를 명확히 알려 첫 비교를 시작할 수 있게 한다.

| 규칙 ID | 동작 |
| --- | --- |
| BP-INPUT-001 | 로컬 입력은 MP4 또는 WebM이며 현재 브라우저에서 재생 가능한 영상이어야 한다. 지원되지 않는 형식에는 형식 제한을, 지원 컨테이너가 손상됐거나 브라우저에서 해독할 수 없으면 재생 실패를 안내한다. |
| BP-INPUT-002 | 로컬 파일은 50MB 이하를 허용한다. 초안에서는 50MB를 50,000,000바이트로 계산하며 상한값을 포함한다. |
| BP-INPUT-003 | 영상 길이는 30초 이하를 허용한다. 실제 길이를 기준으로 판정하며 상한값을 포함한다. 영상을 열 수 없거나 유효한 길이·프레임을 확인할 수 없으면 재생 실패를 안내한다. |

**예시**

- 정상 · 브라우저에서 재생되는 12초 MP4를 연다 → 첫 프레임부터 작업할 수 있다.
- 경계 · 재생 가능한 영상이 정확히 30초이고 50,000,000바이트다 → 두 상한 조건을 충족한다.
- 오류 · 31초 WebM, 50MB 초과 MP4, 지원하지 않는 형식, 손상된 MP4 → 각각 해당 제한 또는 재생 실패 메시지를 표시한다.

**변경 이력** · v0.1 최초 정의.

## 4. BP-LOCAL · 브라우저 내부 처리

**목적**  
사용자가 선택한 영상과 추출한 프레임을 자신의 브라우저에서 비교할 수 있게 한다.

| 규칙 ID | 동작 |
| --- | --- |
| BP-LOCAL-001 | 영상 선택, 프레임 추출, 영역 지정, JPEG 변환과 PNG 생성은 브라우저에서 처리한다. 사용자 영상, 프레임·크롭 이미지 및 생성된 PNG의 서버 전송·영구 앱 저장을 범위에서 제외한다. 사용자가 저장을 요청한 PNG는 기기로 다운로드한다. |
| BP-LOCAL-002 | 활성 영상·프레임·선택 영역·설정은 페이지 작업 상태로 관리한다. 영상을 교체하면 필요 없어진 임시 객체 URL을 해제한다. 새로고침 또는 탭 종료 후 다시 비교하려면 영상을 다시 연다. |

**예시**

- 정상 · 로컬 영상을 열어 PNG를 저장한다 → 결과는 기기의 다운로드 파일로 제공된다.
- 경계 · PNG를 저장한 뒤 페이지를 새로고침한다 → 작업 화면을 다시 시작하며 이미 저장한 PNG는 기기에 있다.
- 오류 방지 · 영상을 여러 번 교체한다 → 교체된 영상의 임시 URL을 해제하고 현재 영상만 비교한다.

**변경 이력** · v0.1 최초 정의.

## 5. BP-SAMPLE · 샘플 제공

**목적**  
로컬 파일 없이 실습을 시작할 수 있고 결과를 시연할 수 있게 한다.

| 규칙 ID | 동작 |
| --- | --- |
| BP-SAMPLE-001 | `샘플로 시작`에서 출처와 배포·시연 사용 권리를 확인한 짧은 클립을 제공한다. 시작 화면의 정지 이미지는 같은 클립에서 가져오며, 영상 열기 이후 로컬 영상과 동일한 비교·저장 흐름을 제공한다. |

**예시**

- 정상 · 사용자가 샘플을 연다 → 타임라인에서 장면을 고르고 영역을 비교하고 저장할 수 있다.
- 경계 · 사용자가 로컬 파일 입력 오류를 만난다 → 샘플 버튼으로 실습을 다시 시작할 수 있다.
- 오류 · 후보 클립의 배포 권리를 확인하지 못한다 → 권리를 확인할 수 있는 후보로 교체한다.

**변경 이력** · v0.1 최초 정의.

## 6. BP-COMPARE · 프레임, 영역 및 압축 비교

**목적**  
동일한 장면과 위치에서 설정을 하나씩 바꿔 변화의 원인을 확인하도록 한다.

| 규칙 ID | 동작 |
| --- | --- |
| BP-COMPARE-001 | 원본과 변환본은 현재 영상에서 캡처한 동일 프레임과 시점을 사용한다. 타임라인에서 다른 프레임을 선택하면 기존 선택 영역을 초기화한다. |
| BP-COMPARE-002 | 관심 영역은 원본 영상 안에서 면적이 있는 사각형이다. 드래그와 좌표·크기 입력은 동일한 영역을 갱신한다. 두 카드의 확대에는 같은 상대 위치와 표시 크기를 사용하며, 각 결과의 실제 영역 픽셀 크기를 따로 표시한다. |
| BP-COMPARE-003 | 해상도와 JPEG 품질은 독립적으로 조절한다. 변환은 원본 비율을 유지해 축소한 프레임에 실제 JPEG 인코딩을 적용한다. 같은 해상도에서 JPEG 품질을 바꾸면 픽셀 크기는 유지된다. 설정 변경은 원본·시점·선택 영역을 유지한 채 변환본에 적용한다. |

**예시**

- 정상 · 8초 프레임의 200 × 120 px 영역을 골라 해상도를 50%로 바꾼다 → 대응 위치를 같은 표시 크기로 비교하고 변환 영역에 100 × 60 px을 표시한다.
- 경계 · 같은 50% 해상도에서 JPEG 품질만 바꾼다 → 변환 미리보기가 다시 생성되고 영역 크기는 100 × 60 px을 유지한다.
- 오류 방지 · 시점을 9초로 이동한다 → 두 카드가 새 프레임으로 갱신되고 8초의 선택 영역은 지워진다.

**변경 이력** · v0.1 최초 정의.

## 7. BP-EXPORT · 비교 PNG 저장

**목적**  
사용자가 본 비교 결과와 조건을 설명과 함께 재사용할 수 있게 한다.

| 규칙 ID | 동작 |
| --- | --- |
| BP-EXPORT-001 | 유효한 영역을 선택하고 현재 설정의 양쪽 미리보기가 모두 준비된 상태에서 `비교 PNG 저장`을 활성화한다. 프레임·영역·설정이 갱신되는 동안에는 최신 결과가 완성되기 전까지 저장을 비활성화한다. |
| BP-EXPORT-002 | 한 장의 PNG에 같은 영역의 원본·변환 확대 이미지를 나란히 배치한다. 각 패널에 원본·변환 라벨, 시점, 실제 영역 가로·세로 픽셀 수를 넣고, 적용한 해상도 비율과 JPEG 품질 값을 표시한다. |

**예시**

- 정상 · 8초 장면의 영역을 50% 해상도와 JPEG 품질 70으로 비교한 뒤 저장한다 → PNG에 두 영역, 시점, 실제 크기와 두 설정값이 표시된다.
- 경계 · JPEG 품질을 바꾼 직후 변환 결과를 생성 중이다 → 새 결과가 나타나면 저장을 활성화한다.
- 오류 방지 · 타임라인으로 이동한 뒤 새 영역을 지정하지 않았다 → 저장은 비활성 상태이며 원본 카드에 영역 선택 방법이 표시된다.

**변경 이력** · v0.1 최초 정의.

## 8. BP-STATE · 갱신과 오류 복구

**목적**  
사용자가 결과의 준비 상태와 실패 원인을 이해하고 비교 작업을 다시 시작할 수 있게 한다.

| 규칙 ID | 동작 |
| --- | --- |
| BP-STATE-001 | 영상 읽기, 프레임 이동, 압축 갱신 중에는 해당 조작부 근처에 상태를 표시한다. 시점이나 설정을 연속으로 바꾸면 가장 최근 선택에 해당하는 결과만 현재 미리보기와 저장에 반영한다. |
| BP-STATE-002 | 입력 오류는 영상 열기 버튼 가까이에 원인과 다음 행동을 표시한다. 영상 열기를 다시 시도하거나 샘플로 전환할 수 있다. 압축·저장이 실패하면 완료 상태 대신 실패를 안내하고 같은 설정으로 재시도할 수 있게 한다. |

**예시**

- 정상 · 새 영상을 읽는 동안 `영상을 여는 중…`이 표시된다 → 프레임이 준비되면 작업 컨트롤을 활성화한다.
- 경계 · 해상도와 품질을 연속으로 바꾼다 → 마지막으로 선택한 조합의 미리보기와 저장값만 사용한다.
- 오류 · 현재 브라우저에서 MP4를 재생할 수 없다 → 재생 실패를 안내하고 `내 영상 열기` 및 `샘플로 시작`을 제공한다.

**변경 이력** · v0.1 최초 정의.

## 11. BP-AI · 얼굴 특징점 검수

| 규칙 ID | 동작 |
| --- | --- |
| BP-AI-001 | 두 최신 프레임이 준비된 상태에서 사용자가 요청하면 원본 및 JPEG 결과를 같은 모델로 분석한다. 원본의 전체 또는 겹치는 부분 영역에서 검출한 얼굴을 기준으로 대응 얼굴을 찾는다. 원본을 검출하면 얼굴·눈·입 자동 선택을 제공한다. |
| BP-AI-002 | 대응 얼굴이 있을 때 눈과 입의 지정 특징점 위치 평균 차이를 원본 px 및 원본 얼굴 너비 대비 비율로 각각 표시한다. 얼굴 미검출에는 숫자 대신 원본 또는 변환본 미검출 메시지를 표시한다. |
| BP-AI-003 | 영상·시점·해상도·품질이 변경되면 분석 결과를 지우고 이전 계산 결과의 반영을 차단한다. 모델 자산은 요청 시 내려받으며 프레임·특징점·수치는 브라우저의 작업 상태에서만 사용한다. 분석 오류 이후 수동 비교와 PNG 저장을 계속 사용할 수 있다. |

변경 이력 · 2026-11-25 얼굴 분석 확장에 적용.
